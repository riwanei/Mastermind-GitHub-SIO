MASTERMIND le défi

Jeu de logique : casse le code secret

Niveau

Choisis un mode de jeu

Les règles

  • Trouve la combinaison secrète de pions colorés. Une couleur peut apparaître plusieurs fois.
  • Après chaque essai : n pions de la bonne couleur bien placés et n pions de la bonne couleur mal placés.
  • Au clavier : touches 1 à 8 pour poser un pion, Retour arrière pour en retirer un, Échap pour tout effacer, Entrée pour valider.
